Ctrl+G, n’importe quand

Le chat s’ouvre en plein écran, comme vim. Tu quittes, ton terminal revient exactement comme avant — et ce que tu tapais aussi.

Chiffré de bout en bout

AES-256-GCM. Le serveur ne voit passer que du bruit : seuls ceux qui ont le code du salon peuvent lire.

🌍

Marche partout

4G, wifi de la fac, box de tes parents : tout passe en HTTPS sortant. Aucun port à ouvrir, aucune IP à échanger.

📬

Rien ne se perd

Ordi en veille ? Les messages sont gardés 48 h et arrivent dès que tu te reconnectes. Historique local illimité.

🪶

Zéro dépendance, 100 % lisible

~900 lignes de Node.js, aucune librairie npm. Tu peux tout lire avant de l’installer — et même héberger ton propre relais.

L’astuce des notifs dans le shell.

Un petit daemon écoute tes salons en arrière-plan. Chaque terminal zsh ouvert s’inscrit auprès de lui. Quand un message arrive :

relais
message chiffré
poussé en streaming HTTPS
déchiffre
daemon
dépose + SIGUSR1
dans la boîte de chaque shell
signal
zsh
TRAPUSR1 → zle -I
affiche au-dessus, redessine ta ligne

Si un programme plein écran tourne (vim, htop…), la notif attend sagement le prochain prompt pour ne rien casser. Sous bash, elles s’affichent au prompt suivant.

FAQ

Qu’est-ce qu’il me faut ?

Node.js 18 ou plus (brew install node sur Mac, sudo apt install nodejs sous Linux) et un terminal avec zsh ou bash. Sous Windows, passe par WSL.

Mes messages sont-ils privés ?

Oui. Chaque salon a un secret aléatoire de 256 bits, contenu dans le code d’invitation. Il sert à chiffrer les messages (AES-256-GCM) avant qu’ils quittent ton ordi. Le relais ne voit que du chiffré. Par contre : toute personne qui a le code peut lire et écrire — ne le partage qu’avec tes potes.

Pourquoi faut-il un serveur si c’est chiffré ?

Pour que deux ordis sur des réseaux différents se trouvent sans ouvrir de ports. Le relais (un serveur ntfy) ne fait que passer les messages chiffrés. Tu peux aussi utiliser le tien : tchat server https://ton-relais.exemple avant de créer tes salons.

Je peux changer le raccourci Ctrl+G ?

Oui : ajoute export TCHAT_KEY='^T' dans ton ~/.zshrc, avant la ligne source de tchat.

Je préfère installer à la main. 
git clone https://github.com/EthanPasquier/tchat.git ~/.tchat-app
echo 'source ~/.tchat-app/shell/tchat.zsh' >> ~/.zshrc
exec zsh
Comment désinstaller ? 
tchat daemon stop
rm -rf ~/.tchat-app ~/.tchat ~/.local/bin/tchat
# puis retire la ligne « tchat » de ton ~/.zshrc ou ~/.bashrc
